# Correctif Money Drop V138.2

Ce correctif apporte deux changements :

1. aucune trappe vide n'est obligatoire ; toute la cagnotte peut être répartie sur toutes les réponses ;
2. une banque de 60 questions variées est ajoutée.

## Projet déjà en V138 ou V138.1

1. Remplacer `components/money-drop/money-drop-experience.tsx`.
2. Exécuter dans Supabase le fichier `supabase/nostra-v138.2-correctif-money-drop.sql`.
3. Redéployer le site sur Vercel.

## Money Drop pas encore installé

Utiliser le fichier complet `supabase/nostra-v138-money-drop.sql`, puis déployer tous les fichiers du correctif V138 original ou le projet complet V138.2.
