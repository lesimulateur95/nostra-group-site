# Nostra Group V138.4 — Money Drop : 50 questions finales

## Nouveautés

- 50 questions finales supplémentaires.
- Banque totale de départ : 250 questions.
- 200 questions classiques et 50 questions finales.
- Les finales sont rangées directement par thème.
- 10 thèmes de finale, avec 5 questions chacun.
- Chaque finale possède deux réponses et deux trappes.
- Les bonnes réponses sont équilibrées entre A et B.
- Une question finale ne peut être utilisée que pendant la dernière manche.
- Une question classique ne peut pas être utilisée pendant la dernière manche.
- Tirage aléatoire automatiquement adapté au type de manche.
- Séparation « Questions classiques » / « Questions finales » dans le Dashboard.
- Possibilité de créer manuellement une nouvelle question classique ou finale.

## Thèmes des finales

Histoire, Géographie, Sciences, Espace, Technologie, Sport, Cinéma & séries, Musique, Littérature & français et Automobile.

## Installation sur une V138.3 existante

1. Remplacer les fichiers présents dans le ZIP correctif V138.4.
2. Ouvrir Supabase, puis SQL Editor.
3. Exécuter `supabase/nostra-v138.4-money-drop-50-finales.sql`.
4. Redéployer le site sur Vercel.
5. Ouvrir `/dashboard/jeux/money-drop`.

Le SQL est réexécutable. Il met à jour les 50 finales sans créer de doublons.

## Nouvelle installation

Exécuter `supabase/nostra-v138.4-money-drop-complet.sql`, qui comprend le module Money Drop, les 200 questions classiques et les 50 finales.
