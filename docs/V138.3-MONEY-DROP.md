# Nostra Group V138.3 — Money Drop

## Installation sur une V138 ou V138.2 déjà installée

1. Déployer les fichiers modifiés sur GitHub/Vercel.
2. Dans Supabase, ouvrir **SQL Editor → New query**.
3. Exécuter `supabase/nostra-v138.3-money-drop-200-questions.sql`.
4. Recharger `/dashboard/jeux/money-drop`.

Le correctif conserve les questions ajoutées manuellement. Les anciennes questions livrées par Nostra sont mises à jour et les nouvelles sont ajoutées sans doublon.

## Nouvelle installation complète

1. Déployer le projet complet.
2. Exécuter `supabase/nostra-v138-money-drop.sql` dans Supabase.
3. Ouvrir `/dashboard/jeux/money-drop` avec le compte Gérant.
4. Configurer puis activer Money Drop.

## Banque de 200 questions

La banque inclut exactement **200 questions de départ**, réparties dans **20 thèmes de 10 questions** :

- Automobile
- Culture générale
- Géographie
- Histoire
- Sciences
- Espace
- Technologie
- Sport
- Football
- Cinéma & séries
- Musique
- Cuisine
- Nature
- Animaux
- Logique & maths
- Jeux de société
- Jeux vidéo
- Littérature & français
- Mythologie
- France & patrimoine

## Gestion par thèmes

Dans le Dashboard, le Gérant dispose de :

- boutons de filtre pour chaque thème ;
- compteurs du nombre de questions actives et du total ;
- questions regroupées par thème dans le menu de sélection ;
- tirage aléatoire global ou limité à un thème précis ;
- ajout de nouvelles questions directement dans le thème choisi ;
- activation ou désactivation individuelle de chaque question.

## Règles de répartition

L’équipe doit répartir la totalité de la cagnotte. **Aucune trappe vide n’est obligatoire** : une, plusieurs ou toutes les trappes peuvent recevoir de l’argent.

## Visibilité civile

Quand Money Drop est désactivé dans le Dashboard, sa carte disparaît totalement de Nostra Motors et l’accès direct à la page civile est bloqué.
